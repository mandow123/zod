# KAI CloudPay 华为应用市场交接清单

更新日期：2026-08-15

这份清单只针对华为应用市场 Android 版本。华为 APK 构建不依赖 Expo/EAS；只有以后启用 Expo 推送时才需要绑定 Expo 项目。

## 你需要提供给团队

### 开发者与主体

- 已完成企业实名认证的华为开发者联盟账号，并在 AppGallery Connect 给发布人员分配所需权限。
- 运营主体法定名称、统一社会信用代码、注册地址、联系人、支持电话和支持邮箱。
- `com.kaicloud.marketplace` 是否曾在华为或其他 Android 商店上传过；如上传过，提供已使用的最高 `versionCode`，如从未上传则书面确认“从未发布”。
- APP 备案号与备案主体信息。未完成 APP 备案时，先走邀请测试，不把测试包称为正式上架包。
- AppGallery Connect 中创建的应用记录，包名必须为 `com.kaicloud.marketplace`。

### 法务与业务

- 以运营主体名义发布的隐私政策、用户协议和账户注销说明的最终法务文本。
- ICP/增值电信业务许可或备案信息，以及华为后台按应用分类要求补充的其他资质文件。
- 对“人民币充值为 KAI 卡时、卡时购买云算力”的业务定性结论。提交正式版前应向华为审核或商务渠道书面确认该模式应使用华为 IAP、Payment Kit、商户服务，还是允许现有支付宝/微信支付；未确认前不能凭经验选择。
- 如果希望公开供应商累计收益，提供供应商明确授权和展示规则；没有授权时只能展示匿名平台统计或明确标注的预计收益。

### 商店素材

- 最终应用中文名称、短介绍、完整介绍、应用分类和搜索关键词。
- 客服联系方式、版权信息、隐私政策公网链接和用户协议公网链接。
- 审核测试账号；短信尚未接通时需提供审核可用的临时登录路径及说明，正式发布前再切换真实短信。
- 3 至 5 个参加邀请测试的华为账号。

## 团队负责生成

- 使用长期保管的上传密钥签名的正式 APK；包名、版本号、target API、权限和证书指纹写入发布报告。
- APK SHA-256、前端源码指纹、安装设备实际文件哈希和冷启动报告。
- 不含 `.env`、密钥、口令、临时数据库、依赖缓存和构建缓存的源码 ZIP。
- 应用图标、启动图、手机截图、功能说明和审核说明。
- 隐私数据清单、Android 权限用途、第三方 SDK 清单、账户注销入口说明。
- 供应商上架链路、买方购买链路、资产状态和异常退款的测试证据。
- 邀请测试版本问题清单及修复记录。

## 上传前技术门禁

- 正式 APK 内的 API 地址只能是 `https://cloudpay.kai.com`，不得包含 `10.0.2.2`、`/__e2e/` 或本地测试开关。
- `https://cloudpay.kai.com/mobile/v1/health`、`/mobile/v1/readiness`、隐私政策、用户协议和账户注销页面均可公网访问且返回正确内容。
- 资源录入、资源审计、价格审计、节点接入、挂牌、卡时下单、开通、计费、停止、退款和供应商结算全部使用正式后端。
- 只有资源审计与价格审计都有效、挂牌为 active、节点可交付的资源才能真实购买。
- 演示资源不得进入正式可支付市场；邀请测试中的演示资源必须明确标识并使用沙盒支付。
- 首次处理个人信息前展示隐私提示；隐私政策能从主界面在四次以内点击或滑动访问，并列明处理目的、方式、范围、主体联系方式、用户权利和第三方 SDK。
- 账户注销、数据删除、短信验证、支付回调和退款回调均使用真实生产服务。
- 最新候选包必须在华为真机或华为云测试设备完成安装、登录、上架、购买和异常恢复测试。

## 建议上架顺序

1. 在 AppGallery Connect 创建应用，核对包名和企业主体。
2. 上传邀请测试 APK，建立内部或外部测试群组。
3. 用华为真机完成资源方上架、买方购买、卡时结算和账户注销测试。
4. 补齐 APP 备案、隐私、支付模式确认和应用资质。
5. 重新构建正式 APK，不复用本地验收包。
6. 上传正式包、图标、截图、介绍、隐私链接和审核账号。
7. 提交审核；审核反馈只在同一主项目修复，重新生成包和哈希。
