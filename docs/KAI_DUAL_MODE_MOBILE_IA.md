# KAI Cloud 手机版双视角布局 V1.0

状态：产品布局定稿，尚未实施。  
主执行基线为 `KAI_CLOUD_MASTER_EXECUTION_PLAN.md`；本文保留双视角交互细节，如有冲突以主方案为准。  
目标：同一个登录账号在“使用算力”和“提供算力”之间一键切换，不注册两套账号、不混合两套任务。

## 1. 核心决定

用户界面不使用生硬的“买方/卖方”，统一称为：

`使用算力 / 提供算力`

这两个是同一身份下的工作视角，不是两个账号，也不是两套余额：

- 登录状态、实名认证、组织关系、KAI 卡时账户和安全设置共用；
- 首页、底部导航、消息默认分类和主要动作随视角切换；
- 订单、账本和审核记录仍由服务端按用户/组织权限隔离；
- 切换视角只改变界面上下文，不会提高权限或绕过供应商审核。

新用户默认进入“使用算力”。系统记住当前设备最后一次选择。

## 2. 一键切换器

在五个一级页面顶部标题下方放固定分段开关：

```text
┌──────────────────────────────────┐
│ KAI Cloud                    通知 │
│  [ 使用算力 ]   [ 提供算力 ]      │
└──────────────────────────────────┘
```

- 点击另一侧立即切换，使用轻微横向过渡，不重新登录；
- 切换后落到相同语义的一级页面：买方首页 ↔ 供应工作台、市场 ↔ 资源；
- 未提交的需求或资源草稿自动保存，切换不会丢失；
- 结账、付款确认、资源审核表单等关键深层页面不显示切换器，先返回一级页面，避免误触中断流程；
- 未开通供应资格的用户仍可进入“提供算力”视角，但看到的是清晰的开通步骤和预览，不出现“已可上架”的误导状态。

## 3. 使用算力视角

底部导航：

`首页 / 市场 / 订单 / 消息 / 我的`

### 首页

- 卡时余额、冻结卡时、充值和账单；
- 待支付、开通中、待验收和使用中任务；
- GPU、模型/Token、云主机、存储和预留容量快捷入口；
- 最近购买与退款，不展示供应商经营数据。

### 市场

- 浏览已经完成资源验真和价格审核的资源；
- 主价格显示 KAI 卡时/原生资源单位，人民币只作为参考价；
- 显示地区、交付、可售时间、资源审核与价格审核标识；
- 找不到资源时显示次级动作 `发布算力需求`，不占用底部主按钮。

### 订单

- 待支付、开通中、待验收、使用中、已完成、退款/争议；
- 以交付时间线和“下一步需要我做什么”为主；
- 不混入供应方待交付订单。

### 消息

默认显示购买侧消息：订单、卡时、交付、退款和系统。可以在消息页切换“全部”，查看另一视角通知。

### 我的

个人/组织身份、KAI 卡时账户、需求、发票合同、设备安全、协议与账户删除。

## 4. 提供算力视角

底部导航：

`工作台 / 资源 / 上架 / 消息 / 我的`

中间的 `上架` 是抬高的主按钮，继续使用明确的 `+` 图标。它只在提供算力视角出现，因此用户不会再猜“发布什么”。

### 工作台

- 供应资格与待补材料提醒；
- 待审核、待交付、使用中、即将到期和待清理数量；
- 今日/本月成交卡时、待结算、已结算摘要；
- 资源在线率、履约率、退款/故障预警；
- 主要动作始终指向最紧急的一项。

### 资源

- 全部、待验真、审核中、可上架、已上架、使用中、暂停/异常；
- 每张卡显示真实配置、可售容量、当前占用、最近在线验证和审核有效期；
- 资源详情包含证据、SLA、清理和重审历史。

### 上架

点击后按用户当前状态进入不同起点：

1. 未认证：供应主体开通；
2. 认证中：查看进度或补材料；
3. 已认证：选择已有资源或添加新资源；
4. 资源未验真：提交在线验真；
5. 已验真：提交建议人民币原生单价和价格依据；
6. 双审核通过：选择库存和可售时间，确认挂牌；
7. 已有草稿：先显示 `继续上次上架`，避免重复填写。

供应商不能手填最终 KAI 卡时价。界面实时预览换算结果，但以服务端价格审核版本为准。

### 消息

默认显示供应侧消息：资质、资源验真、价格审核、补件、订单交付、故障、清理和结算。

### 我的

共用账号与安全设置，同时增加供应主体、成员权限、结算资料、合同发票和服务规则。

## 5. 两个视角之间如何对应

| 使用算力 | 提供算力 | 切换后保持的上下文 |
|---|---|---|
| 首页 | 工作台 | 同一账号和组织 |
| 市场 | 资源 | 当前资源大类/搜索意图可选保留 |
| 订单 | 上架 | 不强行对应，回到各自默认页 |
| 消息 | 消息 | 保留消息对象，切换默认分类 |
| 我的 | 我的 | 停留在同一账号设置层级 |

KAI 卡时账户为两边共用能力：

- 使用算力首页：显示可用、冻结和充值；
- 结账页：显示应付、余额和精确差额充值；
- 提供算力工作台：显示成交、待结算和已结算；
- 两边“我的”：都可以进入完整账本。

## 6. 身份与组织规则

- 一个自然人账号可以同时使用算力和提供算力；
- 供应资格绑定个人主体或组织，不要求重新注册账号；
- 同一用户加入多个组织时，在顶部头像菜单切换当前组织，视角切换仍保持一键；
- `当前组织` 和 `当前视角` 是两个独立状态，不能混为“切账号”；
- 权限由服务端根据当前组织成员关系和供应资质决定，客户端开关不能授予权限；
- 普通成员可以查看供应工作台时，只展示其被授权的数据与操作。

## 7. 用户体验细节

- 不弹出“确认切换角色”对话框；只有未保存的关键表单才先自动保存；
- 两个视角使用同一品牌色，但提供算力视角增加轻微深色/网格线语义，不做成另一款 App；
- 顶部开关显示各自未处理数量，例如 `提供算力 3`，但只显示红点或小数字，不制造焦虑；
- 首次进入提供算力时用三步说明：认证主体 → 验真与价格审核 → 获准上架；
- 空状态必须带下一动作，例如“还没有资源，添加第一台资源”，不能只放空白插画；
- 切回使用算力后，不再出现审核术语、供应商经营数据或上架按钮。

## 8. 验收标准

- 同一账号无需退出即可在两个视角间切换；
- 切换不丢失草稿、不混淆买方订单与供应方交付订单；
- 使用算力视角没有含糊的“发布”主按钮；
- 提供算力视角中间明确显示“上架”；
- “消息”在两个视角都位于“我的”左侧；
- 未认证、审核中、被暂停的用户均不能通过切换器取得上架权限；
- 卡时余额和账本唯一，不因视角切换产生两个账户；
- 返回 App 时恢复上次视角，同时明显展示当前处于哪个视角。
