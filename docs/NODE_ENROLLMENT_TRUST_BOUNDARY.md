# 节点接入可信边界

节点接入协议确认两件事：运行中的 sidecar 持有已登记的 Ed25519 软件密钥；同一软件节点发出的认领和心跳消息具有可校验的签名、顺序和重启边界。

GPU UUID、型号、显存、驱动和 CUDA 版本均由已认证的 sidecar 软件上报。后台会重新规范化数据、计算摘要，并与平台已审核的资源资料和运行策略比对。它们属于“已认证软件节点的自报数据”，不是 TPM 证明、NVIDIA NRAS 证明，也不是厂商提供的硬件远程证明。

因此产品和运营文案只使用：

- “资料已核验”
- “节点在线，可交付”

不得使用“硬件级验真”“真实 H100 认证”“厂商硬件证明”等超出当前证据能力的表述。数据库 ready 约束只校验后台已经接受的节点、心跳、GPU、策略和运行环境事实是否彼此一致；SQL 不会也不能重新验证 Ed25519 签名。
