# ZOD 移动端视觉方向（2026-08-23）

## 1. 交付入口

- 总览对比页：`design-previews/2026-08-23/index.html`
- A 精密控制：`design-previews/2026-08-23/direction-a-control.html`
- B 编辑流：`design-previews/2026-08-23/direction-b-editorial.html`

每个方向都可用顶部“使用算力 / 提供算力”切换目标视角；右上角矩阵按钮可进入全部一级入口、关键二级态、登录态和离线态。查询参数可直接定位，例如：

```text

direction-a-control.html?mode=provider&screen=workspace

```

## 2. 已确认的产品事实与设计边界

本轮以 `zod-mobile-gap-audit.md`、`src/theme.ts`、`src/components.tsx` 与 `src/screens/**` 为事实基线：

- 使用方目标导航为：首页 / 市场 / 我的资产 / 消息 / 我的。
- 提供方目标导航为：工作台 / 资源 / 上架 / 消息 / 我的。
- 双视角导航属于目标态设计，不能声称已经在真实 App 底栏上线。
- 市场必须区分算力租用、预约算力、设备采购，并保留平台保障与 Vast.ai 即时来源差异。
- 提供方流程保留主体认证、资源验真、节点接入、方案与价格双审、挂牌、交付、结算的依赖顺序。
- 余额、订单、库存、收益、未读数、待办数、资产数量与权限必须来自真实服务端；预览统一使用“登录后查看”“—”“等待同步”“暂无已确认数据”。
- 离线不等于库存为零、资源删除或订单取消；预览明确提示恢复连接后再确认交易事实。
- 管理员认证、RBAC、审计和控制台不进入客户移动端导航。

## 3. 三套方向

### A · 精密控制 Control Deck

视觉世界：深海蓝黑、24px 技术网格、状态灯、等宽元信息、6px 小圆角、紧凑操作反馈。

最适合：供应工作台、资源、节点接入、同步异常、履约处理。

优点：

- 基础设施与实时操作辨识度最强。
- 深色背景便于建立告警、在线与同步层级。
- 小圆角和网格减少常规 SaaS 白卡模板感。

取舍：

- 非技术买方可能感到专业密度偏高。
- 深色模式需持续控制低对比装饰线，避免正文被网格干扰。

### B · 编辑流 Editorial Flow

视觉世界：暖纸底色、黑色规则线、品牌蓝大色块、宋体展示标题、少容器和大留白。

最适合：首页、市场、我的、品牌内容与普通买方路径。

优点：

- 信息层级依赖排版本身，模板感最低。
- 业务标题、说明和动作的阅读顺序最自然。
- 暖色底与克制蓝更接近可信、高端但不疏离的消费体验。

取舍：

- 高密度供应运营页面需补充严格的数据表格与状态规范。
- 宋体仅用于展示层，正文和小尺寸控件仍应使用无衬线字体。

### C · 信任凭证 Trust Ledger

视觉世界：冷灰纸、靛蓝、凭证折角、虚线切割、序列与核验章。

最适合：订单、KAI 卡时、资产、履约证据、交易状态历史。

优点：

- 交易和资产具有可追溯、可核验的产品专属性。
- 适合统一订单、账本、证据和生命周期组件。
- 比传统金融渐变卡更克制，也更容易表达状态来源。

取舍：

- 全页面票据化会增加边框噪声。
- 市场与首页应只吸收凭证组件，不应使用整页凭证构图。

## 4. 已选方向规则

妈妈已选择以 **B 编辑流** 作为全局骨架：使用其排版、留白、导航与品牌气质；在提供方页面吸收 **A 精密控制** 的状态灯、网格和异常语法；在订单、钱包和资产详情中吸收 **C 信任凭证** 的序列、核验与时间线组件。

该选择是分层规则，而不是声称已经存在新的混合 HTML 或 React Native 实现。规则按任务分层，而不是在同一组件中混搭：

1. 买方浏览与品牌叙事：B。
2. 提供方实时状态与异常：A 组件语法嵌入 B 骨架。
3. 交易、资产与证据：C 组件语法嵌入 B 骨架。

| 令牌 | A 精密控制 | B 编辑流 | C 信任凭证 | 落地建议 |

| Muted | `#91A9BC` | `#68675F` | `#66778A` | 仅用于辅助信息 |
| Accent | `#4AB8FF` | `#0F62FE` | `#3157C8` | 保留现有品牌蓝家族 |

## 6. 页面与状态覆盖

三套方向共享同一可点击矩阵：

- 使用方五个一级入口：首页、市场、我的资产、消息、我的。
- 提供方五个一级入口：工作台、资源、上架、消息、我的。
- 关键二级态：买方订单、订单详情结构、KAI 卡时、供应工作台、资源、上架中心。
- 关键状态：安全登录、空资产、空订单、目录等待同步、供应资格、资源同步、离线恢复、只读上架保护。

## 7. 可访问性与动效

- 所有可点击项使用原生 `button`，主导航带 `aria-label`，视角与场景可键盘访问。
- 触控目标最小高度 44px；360px 宽度下仍保留完整五项底栏。
- 正文不依赖颜色表达状态；提示同时使用图标、标题和说明。
- 支持 `prefers-reduced-motion`，关闭 240ms 页面入场动画。
- 固定底栏与安全区使用 `env(safe-area-inset-bottom)`。
- 截图发现并修复 A 方向 Hero 文本对比不足；稳定帧重拍后正文和主按钮可读。
