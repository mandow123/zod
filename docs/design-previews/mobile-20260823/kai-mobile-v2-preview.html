比较方法

  • 先切换四套视频艺术字，比较视频画面上的标题气质。
  • 黑夜默认态必须直接可读，不依赖 hover 或 focus 才显现。
  • 触摸底栏仅停驻约 90ms，保留反馈但不制造等待感。
  • 全局字体与视频艺术字互相独立，便于分别定稿。

动效原则

底栏反馈压缩到约 90ms；粒子只出现在首页视频层，并通过两层透明度交替完成换色。减少动态模式保留少量静态粒子，不持续漂移。

数据边界

市场数量、资源健康、待办件数和账户状态均不虚构。三个二级界面只展示结构与字段职责，等待真实业务数据接入。
