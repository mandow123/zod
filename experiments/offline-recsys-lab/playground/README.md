# 推荐算法互动实验室

招聘会现场使用的完全本地、只读互动讲解页。首页先用一条人话流程解释推荐系统，
算法名、指标与实验记录边界通过“查看技术细节”渐进披露。它不训练模型，
不修改冻结基准，也不连接生产环境、外部接口或真实业务数据。

## 启动

从 `experiments/offline-recsys-lab` 运行：

```bash
make playground
```

打开：`http://127.0.0.1:4190/playground/`

无需登录、接口密钥或外部网络。页面直接读取本仓库中已经完成的公开
基准实验 JSON 记录。

## 60 秒演示

1. 先指首页流程：`全部商品 → 候选召回 → 点击预测 → 位置偏差校正 → 最终推荐`。
2. 选用户 A，点击“给这个用户推荐”，展示相似商品召回的确定性前 10 个结果回放。
3. 点击下一步，切换逻辑回归、深度因子分解机和深度交叉网络并读取真实概率校准分组均值；明确
   这不是单样本线上点击率。
4. 在位置偏差中先运行直接统计，再切换归一化逆倾向加权，说明“排第一点击更多”可能只是
   更容易被看见。
5. 点击“打开技术细节”，再按招聘人员兴趣展开召回率、区分能力、有效样本量、
   权重截断与近似检索离线测量。

## 真实性边界

- 热门召回和相似商品召回的前 10 个结果来自冻结公开数据切分，只进行推理回放；生成脚本不训练模型。
- 矩阵分解和双塔召回的冻结运行没有保存用户级模型检查点或前 10 个结果，因此只展示
  已验证聚合指标；缺失记录明确显示为“缺少可回放记录”。
- 点击率冻结实验没有逐行预测；页面展示匿名公开特征行、聚合指标与真实概率校准分组均值，
  绝不把它冒充单样本概率。
- 位置偏差的直接统计、逆倾向加权、归一化加权和所有离散截断结果直接来自完整离线策略评估记录。
- 首页的商品数量动态读取自亚马逊冻结报告，只表示本次公开基准的训练目录规模。

## 可迁移版本

运行 `make export-playground`，会在 `dist/recommendation-systems-playground-portable/`
生成完全自包含的静态目录，并同时生成 ZIP。个人网站接入方法见该目录内的 `README.md`。
