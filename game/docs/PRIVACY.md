# KAI Play 第一阶段隐私说明

更新日期：2026-08-19

KAI Play 处理以下信息：随机生成的玩家 ID、玩家显示名、会话令牌、竞技分与流水、好友房成员关系、牌局手牌与动作、胜负记录、服务端请求时间，以及运行服务所必需的网络地址和错误日志。显式启用计费沙盒时还会保存本地模拟订单和外部引用占位符；这些记录不代表真实卡时交易。

这些信息用于：保持登录状态、完成匹配和牌局、恢复断线状态、防止重复结算、展示战绩、调查作弊或故障。当前产品不接入广告 SDK、不采集通讯录、不请求定位、不读取相册，也不处理支付账户、银行卡或链上钱包。

会话令牌保存在设备安全存储中。服务器 MVP 数据保存在部署者控制的单机数据文件中；正式上线前必须制定明确的保存期限、删除流程、备份策略、访问控制和适用地区的数据主体权利流程。

好友房中的其他玩家会看到你的显示名、当前身份（领队或协作位）、剩余牌数和公开出牌，不会看到你的未出手牌或会话令牌。

该文件是工程阶段的产品边界说明，不应在未补齐运营主体、联系渠道、部署地区、第三方清单、保存期限和用户权利流程时直接作为商店正式隐私政策发布。
