# 豆局用户规则（MVP）

1. 豆局只提供娱乐斗地主。欢乐豆无现金价值，不可购买、出售、提现、赠送、转账或兑换商品与服务。
2. 禁止在线下或第三方平台交易账号、房间结果或欢乐豆；平台不会承认或保障此类交易。
3. 禁止多账号互刷、串通输送、利用漏洞、自动化挂机、篡改客户端、骚扰其他玩家或传播违法内容。
4. 好友房不代表私人或不受规则约束；异常对局仍可进入风控和人工复核。
5. 发现结算或公平性问题时，应保留牌局 ID 和公平校验码，不应通过重复请求尝试获利。
6. MVP 可能因测试、维护或数据结构升级重置娱乐数据；欢乐豆不产生退款或兑付权利。
7. 未成年人保护、运营主体信息、争议处理渠道和适用法律应在选择正式发行地区后由运营方和法律顾问补齐。
